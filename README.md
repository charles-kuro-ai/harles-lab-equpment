## 1. Project Overview

**Technology stack:**
- HTML5, Tailwind CSS v3, Vanilla JavaScript
- Vercel (hosting + serverless functions)
- Formspree (contact and quotation forms)
- Calendly (consultation booking)
- Telegram Bot API (product enquiries, via Vercel serverless function)

**Pages:**
| File | Route | Purpose |
|------|-------|---------|
| `index.html` | `/` | Homepage |
| `products.html` | `/products.html` | Product catalogue with search and filters |
| `product.html` | `/product.html?slug=...` | Individual product detail (data-driven) |
| `services.html` | `/services.html` | Services page |
| `about.html` | `/about.html` | About page |
| `contact.html` | `/contact.html` | Contact and quote request form |
| `privacy.html` | `/privacy.html` | Privacy policy |

**Key files to edit as a business owner:**
- `assets/js/products.js` — product catalogue data
- `assets/js/config.js` — email, phone, Formspree endpoint, Calendly URL
- `assets/images/` — logos and product photographs

## 5. Building the Production CSS

The website uses Tailwind CSS v3 with a real build step (not CDN) for production.

**Build once:**
```bash
npm run build
```

**Watch mode during development** (rebuilds CSS automatically on file change):
```bash
npm run dev
```

The compiled stylesheet is output to `assets/css/styles.css`.

> **Note:** The HTML files currently load both the Tailwind CDN (for rapid preview) and `assets/css/styles.css`. Once the compiled stylesheet exists and you're deploying to production, you can remove the CDN `<script>` tag from each HTML file to reduce page weight. The CDN is safe to leave during development.

## 6. Running a Local Development Server

Because the site uses relative paths (`/assets/...`), you need a local HTTP server rather than opening files directly in a browser.

```bash
npx serve . -l 3000
```

Then visit: [http://localhost:3000](http://localhost:3000)

Alternatively, install a VS Code extension such as **Live Server** and open `index.html`.

> The Telegram serverless function (`/api/telegram-enquiry`) requires Vercel's local development tool to run locally:
> ```bash
> npm install -g vercel
> vercel dev
> ```
> Without `vercel dev`, the Telegram enquiry button will show a user-friendly error and direct visitors to the contact form instead.

## 7. Editing Product Data

All product data lives in one file: **`assets/js/products.js`**

### To add a new product:

1. Open `assets/js/products.js` in a text editor.
2. Copy the structure of an existing product object.
3. Fill in the verified fields. Leave unverified fields as `null`.
4. Set `"status": "draft"` while you are preparing the entry.
5. Change to `"status": "published"` only when you are confident the details are correct.
6. Add the product image to `assets/images/products/` and reference it by filename in the `image` field.
7. Run `npm run build` to rebuild the CSS if you changed any Tailwind classes.

### Product status values:
| Status | Effect |
|--------|--------|
| `"published"` | Visible on the Products page and homepage |
| `"draft"` | Hidden from all public pages |

### To mark a product as featured (shown on the homepage):
Set `featured: true` and `status: "published"`.

### Categories:
Available categories are defined in the `CATEGORIES` object at the top of `products.js`:
`haematology`, `biochemistry`, `immunoassay`, `microbiology`, `urinalysis`, `coagulation`, `molecular`, `pointofcare`, `lab_consumables`

### ⚠️ Content rules:
- Only publish a product when you have verified its name, manufacturer, and description.
- Do not publish specifications unless they come from official manufacturer documentation.
- Do not invent model numbers, test throughput, or clinical claims.

## 8. Replacing Images and Logos

### Company logo
Replace `assets/images/logo-placeholder.svg` with your actual logo file.
- Recommended format: SVG or PNG with transparent background
- Recommended height: 36–40 px display height (provide 2× for retina: 72–80 px tall PNG)
- The footer uses `brightness-0 invert` CSS to show the logo in white — test this works with your logo, or provide a separate white version.

### Hero image
Replace `assets/images/hero-placeholder.svg` with a real photograph of laboratory equipment.
- Recommended size: 1000 × 750 px minimum, WebP or JPEG
- The image is displayed at approximately 500 × 380 px on desktop

### Product images
Add product images to `assets/images/products/` and reference them by filename in `products.js`.
- Recommended size: 800 × 600 px, WebP or JPEG
- Products without an image will show `placeholder-product.svg` automatically

### OG image (social sharing)
Add `assets/images/og-image.jpg` (1200 × 630 px) for social media link previews.

## 9. Configuring Formspree

The contact and quotation form on `/contact.html` sends submissions to Formspree.

### Steps:

1. Go to [formspree.io](https://formspree.io) and create a free account.
2. Click **+ New Form** and give it a name (e.g. "Harles Lab Equipment Enquiries").
3. Set the destination email address (where enquiries should be delivered).
4. Copy the form endpoint URL. It looks like: `https://formspree.io/f/xpwdabcd`
5. Open `assets/js/config.js` and set:
   ```js
   formspreeEndpoint: 'https://formspree.io/f/xpwdabcd',
   ```
6. Test by submitting a real enquiry from the contact page and confirming receipt.

### Free tier limits (verify at [formspree.io/pricing](https://formspree.io/pricing)):
- Free plan: 50 submissions/month at time of writing — suitable for early-stage use.
- Paid plans available if volume increases.

### ⚠️ Important:
- The Formspree endpoint is a public submission URL — it is safe to include in frontend JavaScript.
- Formspree provides spam filtering. Enable it in your Formspree dashboard settings.
- Never mark a submission as successful until Formspree confirms it (the code does this correctly — `res.ok` check).

## 10. Configuring Calendly

1. Create a Calendly account at [calendly.com](https://calendly.com).
2. Create an **Event Type** for laboratory consultations (e.g. "30-min Lab Equipment Consultation").
3. Configure your availability.
4. Copy your scheduling link (e.g. `https://calendly.com/harleslab/consultation`).
5. Open `assets/js/config.js` and set:
   ```js
   calendlyUrl: 'https://calendly.com/harleslab/consultation',
   ```

When a visitor clicks **Book a Consultation**, Calendly opens in a new tab.

### Free tier:
Calendly's free plan allows one event type with unlimited bookings. Verify current plan details at [calendly.com/pricing](https://calendly.com/pricing).

## 11. Setting Up the Telegram Bot

The Telegram product enquiry feature uses a Vercel serverless function. The bot token never reaches the browser.

### Step 1 — Create the bot

1. Open Telegram and search for **@BotFather**.
2. Send `/newbot` and follow the prompts:
   - Choose a display name (e.g. "Harles Lab Enquiries")
   - Choose a username ending in `bot` (e.g. `harleslabenquiries_bot`)
3. BotFather will give you a **bot token** in the format `123456789:ABCdef...`
4. **Keep this token private.** Do not share it or commit it to Git.

### Step 2 — Find your Chat ID

The bot needs to know which chat to send messages to. This is usually your personal Telegram account or a dedicated group/channel.

**For a personal account:**
1. Start a conversation with your new bot by searching for its username and sending `/start`.
2. Visit: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
3. Look for `"chat":{"id":...}` in the JSON response. That number is your chat ID.

**For a group or channel:**
1. Add the bot to the group/channel as an administrator.
2. Send a message in the group.
3. Visit the `getUpdates` URL above and find the group's `"id"` (group IDs are negative numbers).

### Step 3 — Test the bot manually

```bash
curl -X POST "https://api.telegram.org/bot<TOKEN>/sendMessage" \
  -H "Content-Type: application/json" \
  -d '{"chat_id": "<CHAT_ID>", "text": "Test from Harles Lab"}'
```

You should receive the message on Telegram.

### Step 4 — Add credentials to Vercel

**Do not put the token in any code file.** Add it in the Vercel dashboard only (see Section 12).

## 12. Adding Vercel Environment Variables

Environment variables (including the Telegram bot token) must be set in the **Vercel Dashboard**, not in code files.

1. Log in to [vercel.com](https://vercel.com).
2. Open your project.
3. Go to **Settings → Environment Variables**.
4. Add the following:

| Variable Name | Value | Environment |
|---------------|-------|-------------|
| `TELEGRAM_BOT_TOKEN` | Your bot token from BotFather | Production, Preview, Development |
| `TELEGRAM_CHAT_ID` | Your chat ID (e.g. `123456789`) | Production, Preview, Development |

5. Click **Save**.
6. **Redeploy** your project after adding variables — environment variables only take effect on the next deployment.

### Local development with Vercel CLI:
```bash
npm install -g vercel
vercel login
vercel link          # link to your Vercel project
vercel env pull .env # pull environment variables to local .env file
vercel dev           # run local dev server with serverless functions
```

## 13. Deploying to Vercel

### Option A — Deploy via GitHub (recommended)

1. Push the project to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/YOUR_USERNAME/harles-lab-equipment.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) → **Add New Project**.
3. Import your GitHub repository.
4. Leave the Framework Preset as **Other**.
5. Set **Build Command** to `npm run build`.
6. Set **Output Directory** to `.` (the project root).
7. Add your environment variables (Section 12) before deploying.
8. Click **Deploy**.

Vercel will automatically redeploy every time you push to the `main` branch.

### Option B — Deploy via Vercel CLI

```bash
npm install -g vercel
vercel login
vercel --prod
```

### Build command
`npm run build` compiles the Tailwind CSS into `assets/css/styles.css`.

Vercel runs this automatically on each deployment.

## 14. Connecting a Custom Domain

1. In the Vercel Dashboard, go to your project → **Settings → Domains**.
2. Add your domain (e.g. `harleslabequipment.com` and `www.harleslabequipment.com`).
3. Vercel will provide DNS records (CNAME or A record).
4. Log in to your domain registrar and add the DNS records as instructed.
5. DNS propagation typically takes a few minutes to a few hours.
6. Vercel automatically provisions an SSL/TLS certificate (HTTPS).

### After connecting your domain:
- Update `siteUrl` in `assets/js/config.js` to your real domain.
- Update the `<link rel="canonical">` tags in each HTML file.
- Update `sitemap.xml` with your real domain.
- Update `robots.txt` with your real sitemap URL.
- Update `ALLOWED_ORIGINS` in `api/telegram-enquiry.js` if needed.
- Redeploy.

## 16. Common Errors and Fixes

### Tailwind styles not appearing
**Cause:** `assets/css/styles.css` has not been built, or the Tailwind CDN is blocked.
**Fix:** Run `npm run build`. In production, the build command runs automatically on Vercel.

### Telegram enquiry returns 503
**Cause:** `TELEGRAM_BOT_TOKEN` or `TELEGRAM_CHAT_ID` environment variables are not set.
**Fix:** Add them in Vercel → Settings → Environment Variables and redeploy.

### Telegram enquiry returns 502
**Cause:** The bot cannot message the chat ID. The bot has not been started or added to the group.
**Fix:** Send `/start` to the bot on Telegram (for personal chats), or add the bot as admin to your group.

### Formspree form not working
**Cause:** `formspreeEndpoint` in `config.js` is `null` or incorrect.
**Fix:** Set the correct Formspree endpoint URL. Verify the form exists in your Formspree dashboard.

### Product not appearing on site
**Cause:** Product `status` is `"draft"` rather than `"published"`.
**Fix:** Change `status: "published"` in `products.js`. Run `npm run build`.

### Mobile nav not closing
**Cause:** JavaScript is not loading, or there is a console error.
**Fix:** Open browser DevTools → Console and check for errors. Ensure all script `src` paths are correct.

### Logo not showing
**Cause:** `logo-placeholder.svg` path is incorrect, or the logo file was not uploaded.
**Fix:** Place your logo file at `assets/images/logo-placeholder.svg` (or update the `src` in `layout.js`).
